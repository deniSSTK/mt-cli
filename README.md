# mt

`mt` (move to) is a small command-line utility for saving frequently used directories under short names and moving to them quickly.

It is written in POSIX shell and has no external library dependencies. Routes are stored locally in `~/.mt_routes`.

## Installation

The recommended installation method is Homebrew:

```sh
brew install denisstk/tap/mt
```

The Homebrew formula is available at [Formula/mt.rb](https://github.com/deniSSTK/homebrew-tap/blob/main/Formula/mt.rb).

## Shell setup

Because a program cannot change the directory of its parent shell, add the shell function generated by `mt init` to your shell configuration file (for example, `~/.zshrc` or `~/.bashrc`):

```sh
mt init >> ~/.zshrc
source ~/.zshrc
```

Use the configuration file that matches your shell.

## Usage

Create a route interactively:

```sh
mt new
# enter name: work
# enter path: ~/Projects/work
# Saved
```

Move to a saved route:

```sh
mt work
```

List saved routes:

```sh
mt list
```

Delete a route:

```sh
mt delete work
```

`mt` accepts absolute paths, paths beginning with `~`, and paths relative to your home directory.
